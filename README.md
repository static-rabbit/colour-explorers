# colour-explorers

22-NOV-2026

Grid and table-based pages to explore data returned by the color.pizza API.

## Colour Data

Colour data returned via [color-name-api](https://github.com/meodai/color-name-api).

The API was developed by [David Aarne](https://elastiq.ch/) - he also wrote:

- https://meodai.github.io/color-name-api/
- https://names.color.pizza/
  - Color Names is an open, community-grown collection of unique, human-authored color names.
    - A page for every colour - e.g. [make-up-blue](https://names.color.pizza/color/make-up-blue/#306090)
- https://parrot.color.pizza/
- https://www.color.pizza/

He also has a host of things on [Codepen](https://codepen.io/meodai) - e.g.:
  - [Color Name Wheel](https://codepen.io/editor/meodai/pen/019f0e2a-86fc-7ab0-bb81-9fca26a7db6e)
  - [Generative color harmonies](https://farbvelo.elastiq.ch/)
  - [Color naming machine](https://codepen.io/meodai/pen/oNEbJPo)
